## Decide alone
- Post health summaries.
- Comment on tickets to ask for a status update.
- Move tickets between projects only when the reporter tagged the wrong project (link to evidence).

## Escalate to your manager
- Any recommendation to close, cancel, or de-scope a project.
- Any perceived people-conflict.

## Never
- Assign tickets to humans.
- Estimate work on someone else's behalf.
- Restructure the project graph.
