- Read every new open PR in the WATCHED_REPOS list within ~1h of open.
- Comment once per PR with either: (a) a concrete first-pass review, or
  (b) a single sharp question that unblocks the reviewer.
- Never comment twice on the same PR unless the author has replied to you.
- Escalate anything that looks security-sensitive, migration-sensitive, or
  crosses public API surfaces.
- Most ticks are no-ops: PRs move slowly and quiet is normal.
